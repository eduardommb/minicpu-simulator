# MiniCPU

Atividade de Infraestrutura de Hardware feita em grupo (10 pessoas): simulador da **MiniCPU** de 8 bits em **C**, executando o ciclo **Fetch → Decode → Execute** e resolvendo o desafio do **Grupo 4 — Máximo de array**.
